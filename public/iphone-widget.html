STEP 03

다이어리 계정으로 로그인

Scriptable에서 만든 스크립트의 ▶를 누르세요. PC 다이어리와 같은 이메일·비밀번호로 로그인하면 미리보기가 열려요. 이메일 칸에는 @가 포함된 이메일 주소를 입력하세요. 예전 로컬 아이디와 Supabase 대시보드 계정은 별도입니다.

로그인 오류 안내 개선 · v1.1 기존 스크립트를 사용 중이라면 위에서 코드를 다시 복사하고 Scriptable 편집기의 기존 코드를 전체 교체해주세요. 오류가 계속되면 안내 맨 아래의 HTTP 번호와 진단 코드를 알려주세요. 비밀번호는 보내지 마세요.

비밀번호는 저장하지 않습니다. 로그인 연결과 필요한 일정 사본만 아이폰의 Keychain에 보관해요. 이 웹페이지에는 비밀번호를 입력하지 않습니다.

STEP 04

홈 화면에 위젯 추가

  1. 아이폰 홈 화면의 빈 곳을 길게 누르세요.
  2. 편집 → 위젯 추가 또는 ＋에서 Scriptable을 찾아주세요. iOS 버전에 따라 메뉴 이름은 다를 수 있어요.
  3. 중간 크기나 큰 크기 위젯을 추가하세요.
  4. 추가한 위젯을 길게 눌러 위젯 편집으로 들어가세요.
  5. Script에서 CloverWidget을 선택하세요. Parameter는 비워둡니다.

날짜나 일정을 누르면 다이어리가 열립니다. 일정 추가·수정과 할 일 완료는 다이어리에서 해주세요.

갱신 시점은 iOS가 결정해요. 15분 뒤부터 갱신을 요청하지만 정확한 주기는 보장되지 않습니다. PC에서 저장한 내용이 위젯에 즉시 표시되지는 않을 수 있어요. 바로 확인하려면 Scriptable에서 스크립트를 실행해 새로고침하세요.

연결이 끊기면 마지막으로 불러온 사본과 확인 시간을 표시합니다. 로그인이 만료되면 Scriptable에서 다시 로그인해주세요.

PC 기록이 비어 보이면 먼저 웹 다이어리의 본인 계정에서 기존 기록을 가져오고 ‘서버 저장 완료’를 확인하세요. 위젯은 서버의 일정·할 일만 읽습니다.

촬영용 테스트 계정도 쓰고 싶어요

스크립트 화면에서 ‘계정 바꾸기’를 선택하면 됩니다. 본인용과 동시에 쓰려면 Scriptable 위젯을 하나 더 추가하고, 그 위젯의 Parameter에 demo를 넣어주세요. 새 위젯의 로그인 안내를 눌러 테스트 계정으로 연결하면 본인용과 별도로 보관됩니다. 웹의 ‘기존 기록 가져오기’는 테스트 계정에서 누르지 마세요.

아이폰에서 Scriptable의 실제 표시·설치 확인이 필요합니다. 위의 화면은 디자인 예시이며 실제 아이폰에서 촬영한 화면은 아닙니다.
